# research/memoria/

Direcciones de memoria de la Emotion Engine relevantes para Tekken 5,
recopiladas de la comunidad (como pistas) o verificadas por este proyecto.

Ver `direcciones-conocidas.md` para la tabla principal, y los hallazgos
TK5-0009 (parches widescreen/cheats comunitarios) y TK5-0014/TK5-0018 para
contexto.

## Regla de oro de este directorio

Ninguna dirección documentada aquí debe presentarse como "estructura
interna conocida" sin verificación propia. Las direcciones que provienen
de cheats o parches de la comunidad son **pistas de ingeniería inversa**,
nunca hechos confirmados, hasta que se compruebe en el depurador de PCSX2
qué instrucción/dato real ocupa esa dirección (ver plantilla en
`direcciones-conocidas.md`).
