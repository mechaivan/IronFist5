Descubrimiento:
`Kiloutre/TekkenMovesetExtractor` (archivado, GPL-3.0, Python) se anuncia
en su página de distribución en tekkenmods.com como capaz de extraer
movesets de: "Tekken 7 (all versions since Season 2), Tekken Tag 2, Tekken
Revolution, Tekken 6, Tekken 5, Tekken 3DS". El árbol de archivos del
repositorio contiene efectivamente un `T5Aliases.py` (y `T5DRAliases.py`
para Tekken 5: Dark Resurrection, `T4Aliases.py`, `T6Aliases.py`,
`Tag2Aliases.py`).

Sin embargo, el README inspeccionado directamente (texto completo leído)
**solo documenta en detalle** los flujos de exportación/importación para:

1. Tekken 7 (extracción de memoria en vivo, vía Pywin32, mientras el juego
   corre en PC).
2. Tekken Tag Tournament 2 vía CEMU (emulador de Wii U), también por
   lectura de memoria en vivo.

El README **no explica**, en el texto accesible, cómo se realiza
concretamente la extracción para "Tekken 5" (¿memoria en vivo de un PS2
real/emulado vía PCSX2? ¿un archivo ya extraído manualmente? ¿la versión
HD de PS3 "Tekken Hybrid"? ¿la versión arcade?). El propio proyecto fue
marcado como obsoleto por su autor en favor de `Kiloutre/TKMovesets`, cuyo
README no se ha inspeccionado todavía en este proyecto.

Evidencia: Lectura directa de las tres partes del README de
`Kiloutre/TekkenMovesetExtractor` vía GitHub, y del listado de archivos del
repositorio.

Interpretación:
No se puede afirmar, con la evidencia disponible, que esta herramienta
permita extraer movesets directamente de una ISO o ejecución de PS2 de
Tekken 5 retail. Es igualmente plausible que el soporte de "Tekken 5" se
refiera a la reimplementación de su formato de moveset dentro de motores
posteriores (p. ej., si Tekken 6 o Tekken 7 reutilizan/emulan datos de
Tekken 5 vía algún modo de compatibilidad), lo cual sería información sobre
*otro juego*, no sobre el binario PS2 original (ver Regla 5/6 de
`AGENTS.md`: nunca asumir que estructuras de Tekken 6/7 son idénticas a
Tekken 5 PS2 sin verificarlo). Esto se marca explícitamente como
DESCONOCIDO hasta que se investigue el código fuente de `Aliases.py` /
`T5Aliases.py` o el sucesor `TKMovesets` con más profundidad.
