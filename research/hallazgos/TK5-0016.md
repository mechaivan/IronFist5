Categoría: Herramientas / Ecosistema emergente de IA para RE de PS2

Descubrimiento:
A lo largo de 2026 ha emergido un pequeño ecosistema de herramientas que
conectan agentes de IA (asistentes de código) con el flujo de trabajo de
ingeniería inversa de PS2, construido alrededor de Model Context Protocol
(MCP):

- `hkmodd/ps2-recomp-Agent-SKILL`: una "skill" para agentes de código
  (Claude Code / Cursor / Antigravity) que empaqueta conocimiento sobre la
  ISA R5900, el flujo de PS2Recomp, y coordina Ghidra (vía "GhydraMCP") y
  PCSX2 (vía "PCSX2-MCP") para comparación A/B entre la ejecución real del
  juego y el código recompilado.
- `DohmBoy64Bit/RecompHamr`: un "agente de terminal local-first" con una
  skill documentada específicamente para PS2Recomp, que describe 6 fases
  operativas (Setup → First Build → Syscall Bringup → First Boot → A/B
  Comparison → Polish) y un archivo de memoria persistente
  (`REPHAMR_STATE.md`) para retomar sesiones de trabajo largas.
- Herramientas MCP para PCSX2 mencionadas en TK5-0015.

Evidencia: Lectura de los README/documentación de los repositorios citados.

Interpretación:
Esto es información de contexto útil (confirma que la comunidad está
