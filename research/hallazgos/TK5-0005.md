Descubrimiento:
PS2Recomp (`ran-j/PS2Recomp` en GitHub, también espejado/forkeado como
`ej-sanmartin/ps2recomp`) es un recompilador estático experimental de
binarios ELF de PlayStation 2 a C++, con un runtime de ejecución asociado.
Se inspeccionó directamente el README del repositorio (commit visible al
30 de septiembre de 2026). Sus módulos son:

- `ps2xAnalyzer`: escanea el ELF/funciones y escribe un archivo de
  configuración TOML (stubs, skips, parches de instrucciones).
- `ps2xRecomp`: lee el TOML + el ELF, decodifica instrucciones R5900 y
  genera el código C++ de salida.
- `ps2xRuntime`: aloja la memoria emulada, el registro de funciones, el
  despacho de syscalls y stubs de hardware.
- `ps2xIOP`: ejecución de módulos IRX del R3000A (IOP), un kernel IOP
  virtual y HLE genérico de respaldo.

Lo que la herramienta hace automáticamente, según su propia documentación:

1. Parsear el ELF de PS2 para extraer funciones, símbolos y relocaciones.
2. Decodificar instrucciones MIPS R5900 (incluyendo MMI de 128 bits y VU0
   en modo macro) de cada función.
3. Traducir cada instrucción a una operación C++ literal, instrucción por
   instrucción (ejemplo citado textualmente: `addiu $r4, $r4, 0x20` se
   convierte en `ctx->r4 = ADD32(ctx->r4, 0X20);`).
4. Intentar un auto-enlace de relocaciones conocidas en sitios de
   llamada (J/JAL) antes de recurrir a direcciones crudas.
5. Generar wrappers `entry_...` para puntos de entrada estáticos
   adicionales descubiertos internamente.
6. Para saltos/llamadas estáticas no resueltas, caer a
   `runtime->lookupFunction(0x...)` en tiempo de ejecución.
7. Permitir vincular funciones de binarios "stripped" (sin símbolos) a
   mano, mediante sintaxis `handler@0xDIRECCIÓN` en la configuración.
8. Despachar `SYSCALL` recompilado a `runtime->handleSyscall(...)`.

El flujo de trabajo recomendado (según el propio README) es exportar un
mapa de funciones desde Ghidra (CSV/TOML) y usarlo como
`general.ghidra_output`, en vez de depender solo del analizador automático,
especialmente para juegos retail sin símbolos de depuración.

Interpretación:
PS2Recomp automatiza la traducción mecánica de instrucciones MIPS R5900 a
C++ y la generación de un esqueleto de runtime, pero **no identifica
funciones de alto nivel, no reconstruye tipos de datos, no genera lógica
de juego legible, y no implementa por sí solo la GS/VU1/IOP reales**: eso
requiere trabajo de ingeniería inversa específico del título (ver
TK5-0006 y `docs/investigacion/ps2recomp.md`).
