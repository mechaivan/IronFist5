Descubrimiento:
`N64Recomp/N64Recomp` (licencia MIT, según la página del repositorio) es
la herramienta en la que PS2Recomp declara haberse inspirado
explícitamente (ver TK5-0005, sección "Acknowledgments" del README de
PS2Recomp: "Inspired by N64Recomp"). `Zelda64Recomp/Zelda64Recomp`
(licencia GPL-3.0) es el proyecto derivado que usa N64Recomp para producir
un port nativo jugable de The Legend of Zelda: Majora's Mask (y
próximamente Ocarina of Time).

Puntos metodológicos relevantes, extraídos directamente de su propia
documentación:

- Zelda64Recomp explicita la diferencia entre decompilación y
  recompilación estática: "Unlike the past N64 ports, this project is not
  based on the source code provided by a decompilation of the game...
  static recompilation bypasses the need for decompiled source code...
  allowing ports to be made without source code." Pero también reconoce
  que "the reverse engineering work done by the decompilation team was
  invaluable for providing some of the enhancements" — es decir, usan un
  proyecto de decompilación independiente (la decompilación de Majora's
  Mask) como fuente de información complementaria, no como base del port.
- El proyecto es estrictamente de una sola ROM concreta ("It will only
  accept one specific ROM: the US version... It is not an emulator and it
  cannot run any arbitrary ROM"), reforzando que la recompilación estática
  está atada a un build específico, no es genérica.
- Explicita que no se distribuyen assets del juego: "This repository and
  its releases do not contain game assets. The original game is required
  to build or run this project." — un precedente directo y relevante para
  la política de distribución de este proyecto (ver Regla 8 de
  `AGENTS.md`).

Interpretación:
Esta familia de proyectos es la referencia metodológica más cercana
conceptualmente a la visión de este proyecto (recompilación estática +
runtime moderno + exigir que el usuario aporte su propia copia legal), con
la salvedad importante de que N64 es una arquitectura mucho más simple que
PS2 (un solo procesador MIPS de propósito general, sin Vector Units
dedicadas, sin Graphics Synthesizer propio, sin IOP separado). No debe
asumirse que las soluciones de N64Recomp para gráficos (usa RT64, un motor
de render moderno) sean trasladables directamente a PS2: la complejidad
añadida de VU1 + GS es sustancial y specific de PS2 (ver TK5-0014).
