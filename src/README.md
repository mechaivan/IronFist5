# src/

Destinado al código fuente propio del proyecto (reimplementaciones,
sistemas independientes identificados mediante investigación, código de
soporte que no es ni el runtime de recompilación ni herramientas de
análisis).

## Estado actual

Vacío. Siguiendo la Regla 9 de `AGENTS.md` ("no implementar a ciegas"), no
se escribirá código de sistemas de juego en este directorio hasta que
exista investigación documentada (en `docs/` y `research/`) que lo
sustente. Ver `docs/arquitectura/arquitectura-futura.md` para la dirección
conceptual (todavía exploratoria) de cómo podría organizarse este código
en el futuro.
