# runtime/

Destinado al futuro runtime de ejecución para el código recompilado de
Tekken 5 (equivalente a `ps2xRuntime` de PS2Recomp, pero con cualquier
extensión u override específico de este juego, siguiendo el mecanismo de
"Game Override Hooks" descrito en `docs/investigacion/ps2recomp.md`).

## Estado actual

Vacío. No se ha generado código recompilado de Tekken 5 todavía (ver
`docs/desarrollo/primer-milestone.md`, que describe el criterio de éxito
del primer hito técnico, todavía no alcanzado). Este directorio existe
desde ahora para fijar dónde debe vivir ese trabajo cuando comience, pero
no contendrá código hasta que exista un mapa de funciones real del ELF de
Tekken 5 (ver `docs/desarrollo/backlog.md`).
