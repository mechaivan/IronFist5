# Devil Within — plan de investigación

## Fase A: delimitación

- [ ] Recopilar fuentes públicas y registrar su licencia.
- [ ] Separar afirmaciones sobre Devil Within de afirmaciones generales de
      Tekken 5.
- [ ] Crear una lista de términos, pantallas y eventos observables.

## Fase B: behavioral oracle

- [ ] Definir una sesión reproducible de PCSX2.
- [ ] Registrar entradas, estados y transiciones observables.
- [ ] Determinar qué datos puede exponer el depurador sin versionar volcados.

## Fase C: análisis estático

- [ ] Analizar el ELF NTSC-U local con Ghidra.
- [ ] Identificar funciones candidatas y sus referencias.
- [ ] Comparar límites de funciones con la salida de PS2Recomp.
- [ ] Registrar sólo mapas, notas y metadatos permitidos.

## Fase D: comparación

- [ ] Comparar sistemas compartidos y variantes específicas.
- [ ] Validar o refutar hipótesis con más de una evidencia.
- [ ] Publicar hallazgos `DW-XXXX` con estado y reproducibilidad.

Ninguna fase se considera completada por la existencia de una hipótesis o
por una similitud de nombres.
